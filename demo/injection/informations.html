Weekly briefing: what changed this week

Open-weight models kept closing the gap with frontier systems this week, with several new releases focused on long context and tool use rather than raw benchmark scores.

Inference prices continued to fall. Hosted providers now compete mostly on latency and reliability, and on how easy it is to switch between model sizes for different jobs.

Security researchers again warned that agents which read the web and also hold private data are a target: a single poisoned page can try to redirect what the agent does next.
