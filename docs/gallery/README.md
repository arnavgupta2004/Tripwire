# Devpost gallery

Eight 1500×1000 PNGs, regenerated by:

```bash
cd frontend && npx playwright test -c playwright.gallery.config.ts
```

The app screens are the real React UI, rendered by Playwright against the in-browser
mock API (`frontend/e2e/mockApi.ts`): no backend, no keys and no model calls. Data is
the fictional demo persona ("Riya Kapoor") and the demo page served on localhost. No
real personal data appears.
